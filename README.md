# PAID — Shenzhen LST reproducibility repository

> **Auditable autonomous symbolic discovery of urban thermal relationships with admissibility constraints and separated validation**

Public reproducibility repository for the PAID (Physics-aware Autonomous Inquiry & Discovery) study of urban land-surface temperature (LST) in Shenzhen, China. It provides the frozen code, the protocol record, the public analysis-ready tables, and a portable verification layer so that the reported numbers can be recomputed and audited without the authors' machine, without an AES key, and without any network or language-model call.

This repository is a **public** companion. It is not the reviewer package: see *Public vs. confidential* below for the one difference that matters.

`PAID/` holds the **historical implementation** — the frozen Stage 00–05 scripts, agents, libs and renderers as they were actually run. It is kept verbatim as the record of how the frozen products were produced; its scripts import absolute author paths and are **not** meant to be executed by a third party. `release_tools/` holds the **reviewer-portable verifier layer** that replaces them for reproduction: it derives its own root from its file location, needs no absolute path, no key and no network, and recomputes every published number from the shipped tables alone. `verification/` holds `verify_manifest.py`, the release-integrity checker, plus a verification index.

## What this study claims — and does not claim

The formal pre-registered endpoint **passed** on the evaluated locked region (ΔRMSE = **+0.3791 °C**, permutation *p* = **0.005**, 95% CI [0.2761, 0.4814]). The manuscript nevertheless concludes that **no portable urban thermal law was established**; the durable contribution is **methodological**. The repository ships the negative and adversarial results at the same level of visibility as the positive endpoint. Please read `docs/KNOWN_LIMITATIONS.md` and `docs/PROTOCOL_DEVIATION.md`.

## Public vs. confidential — what is and is not here

This repository contains only material cleared for public deposit. Two things are deliberately **not** included:

- **The Changchun reviewer-only row-level table** (`changchun_analysis_ready.csv`). The external-replication dataset derives from a third-party source whose redistribution licence is **not confirmed**; its slim analysis-ready table stays reviewer-only and is excluded from this public repository until the licence is confirmed. A derivation recipe (source identifiers plus the exact QC/derivation steps) is carried in `docs/THIRD_PARTY_DATA_REVIEW.md` and `data/changchun/DATA_DICTIONARY.md` so the table can be regenerated by a third party from the original source. Because of this, the public repository does **not** run the Changchun row-level verification check by default.
- **The raw Shenzhen source rasters (~857 MB).** Their redistribution rights are unconfirmed; they are represented here by provenance records and by the exact frozen analysis-ready values actually used. Raw Changchun satellite products (~6.1 GB) are likewise not redistributed.

Region C (the locked evaluation region) is described **only as the public package actually contains it**: the full 9-column `data/shenzhen/zone_C_analysis_ready.csv` table ships so the published statistic can be recomputed, and it is **scientifically spent under Protocol V1** — a locked-region evaluation under a documented protocol deviation, not a pristine confirmatory holdout. See `docs/REGION_C_PROVENANCE.md` and `docs/PROTOCOL_DEVIATION.md`.

## Reproducing the results

Start with `QUICKSTART.md`. The one command that runs the whole portable layer is:

```bash
python3 release_tools/run_all_release.py
```

The headline numbers and where they live are tabulated in `QUICKSTART.md`. For the public tree, one verifier (`CHANGCHUN_NUMERICS`) cannot run because the restricted Changchun table is absent, so it is **not part of the default public verification path**. The full **13/13 `RELEASE VERIFICATION: ALL PASS`** result is a property of the **confidential reviewer release**, which includes the restricted Changchun table — it is **not** a claim about this public repository. Do not expect, and do not report, "clone and run 13/13" for this public tree.

**No LLM or network service is required to reproduce any published number.** The role "agents" are deterministic Python functions governed by frozen prompt specifications; the discovery search is a deterministic greedy + local-refinement loop over a frozen operator space. See `docs/MODEL_AND_AGENT_DISCLOSURE.md` and `docs/LLM_PROVENANCE_AUDIT_v1_2_1.md`.

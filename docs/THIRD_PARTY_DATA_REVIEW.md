# THIRD-PARTY DATA REVIEW — Changchun external-replication dataset

**Purpose.** The Changchun 2021 dataset is the only third-party data in this package. This review
records what is included, what is withheld, and the **redistribution status** — so the author can
decide what may be publicly deposited and what must stay reviewer-only.

**Bottom line.** The slim analysis-ready table used by the manuscript is included **for review only**.
Its redistribution status is **not confirmed**, so it must **not** be placed in a public deposit until
the licence is checked. The raw Changchun satellite products are **not** redistributed at all.

---

## 1. What is in the package

| Item | Path | Size | Status |
|---|---|---|---|
| Slim analysis-ready table (the only Changchun file shipped) | `data/changchun/changchun_analysis_ready.csv` | ~7 MB | **Reviewer-only** (licence unconfirmed) |
| Data dictionary | `data/changchun/DATA_DICTIONARY.md` | — | ships |
| Export QC record | `data/changchun/_export_checks.json` | — | ships |

The shipped table is **100,676 rows × 16 columns**; the QC rule actually applied by
`s05_04_external_replication.py` keeps rows finite in `[LST, NDVI, DEM, BD, BVD, Height_mea, row, col]`
with `LST ∈ (0, 70] °C` and `NDVI ∈ [−1, 1]`, giving **100,676 → 100,647** rows used. Columns:
`id, left, top, right, bottom, LST_mean, NDVI_mean, DEM_mean, BD, BVD, Height_mea, NDWI_mean,
GDP_mean, POP_mean, row_index, col_index`. Only `LST_mean, NDVI_mean, DEM_mean, BD→X_BD,
BVD→X_VolDens, Height_mea→X_BH, row_index, col_index` are used by the replication.

## 3. Why the table is treated as reviewer-only

The source is described in the manuscript as a third-party GIS dataset. **No licence file, no
attribution string, and no terms-of-use document accompanied the source layers in the author's
working copy** (the delivered files are `.dbf`, `.shp`, `.tif` products without a LICENSE/README).
In the absence of a confirmed redistribution licence, the safe and honest default is:

- **include** the slim derived table **for the reviewer**, because the manuscript's post-hoc external
  replication cannot be checked otherwise; and
- **exclude** it (and all raw products) from any **public** deposit until the licence is confirmed.

This is the same posture the manuscript already takes: the external replication is **explicitly
post hoc**, not a prospective confirmation, and the dataset is **not** redistributed as raw data.

## 4. Author checklist before any public deposit

- [ ] Identify the original provider of the Changchun source and its licence (e.g. an open-data portal,
      a project agreement, or a citation requirement).
- [ ] If redistribution is **permitted**: record the licence and attribution, then the slim table may
      move from reviewer-only to public.
- [ ] If redistribution is **not permitted**: keep the slim table out of the public deposit; instead
      publish a **derivation recipe** (source identifiers + the exact QC/derivation steps in
      `DATA_DICTIONARY.md`) so the table can be regenerated by a third party from the original source.
- [ ] Confirm the derived-table status: some licences restrict **derivative** redistribution even when
      the source is shareable — check this explicitly.
- [ ] Update the availability statement and `DATA_PROVENANCE.md` §2 once the status is known.

## 5. Attestation

- No fabricated source, licence, DOI or attribution appears anywhere in this package.
- The raw Changchun products are **not** shipped; only the derived slim table is, and it is labelled
  reviewer-only in `DATA_PROVENANCE.md`, `data/changchun/DATA_DICTIONARY.md` and the availability
  placeholder.
- `release_tools/verify_changchun_release.py` recomputes the six frozen Changchun numbers from the
  shipped table alone, so the replication is checkable **without** the raw products. Result: PASS 6/6.

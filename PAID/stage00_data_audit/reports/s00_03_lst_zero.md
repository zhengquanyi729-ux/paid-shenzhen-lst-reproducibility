## 判定

全市域 LST 的 0 值**不是真实低温观测**，而是**研究区外的填充值**，证据链如下：

1. 99.90% 的 0 值像元同时是 DEM nodata，99.50% 同时是 NDVI 填充；三个独立图层的填充掩膜大面积重合，
   说明 0 是制图时的统一"区外/海面"填充，而非 LST 反演产物。
2. 0 值像元落在深圳行政边界**之外**的比例为 99.911%，而市界内像元几乎不为 0（0.107%）。
3. 连通性检验：100.00% 的 0 值像元至少有一个 0 邻域，远高于随机打散的 95.54%，
   表明 0 值呈**大块连片**分布，符合边界外填充的形态，不符合自然低温斑块的形态。
4. 非零 LST 中位 38.23 °C、最大 69.17 °C，量级物理合理；负数仅 20 个（占非零的 0.0009%），可忽略。

**因此分类型掩膜规则为：**

| 数据 | 规则 | 依据 |
|---|---|---|
| 全市域 LST | `LST==0` 与 `LST==-9999` **一律判为无效**，不进入任何统计 | E1+E2+E3+E4 四重证据 |
| 研究区 LST | 0 值仅 223 个（0.024%），需逐像元核查后再定；**默认标记为"待核"而非直接删除** | 证据不足，不预设删除 |
| CSV 中 `LST_mean==0` 的网格 | 标记为 `lst_suspect`，保留但加标记位 | 同上 |

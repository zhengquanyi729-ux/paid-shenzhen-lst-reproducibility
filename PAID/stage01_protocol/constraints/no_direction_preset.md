# §3.2 无方向预设声明（系统提示词禁用清单）

框架依据：§3.2「不得在系统提示词中规定 NDVI 必须单调降温、SVF 必须升温或降温或
建筑高度必须产生某一方向的热响应；不预设最优空间尺度、固定函数形式、单一显著阈值或特定交互组合。」

因此，向任何发现/实验 Agent 注入的系统提示词中，**以下主张与词条一律禁止**：

1. 禁止在系统提示词中规定 NDVI 必须单调降温（或升温）。
2. 禁止规定 SVF 必须升温或必须降温。
3. 禁止规定建筑高度/体量必须产生某一方向的热响应。
4. 禁止预设最优空间尺度（不得指定唯一 r）。
5. 禁止预设固定函数形式（不得指定线性/幂律/树模型等）。
6. 禁止预设单一显著阈值（不得写死如 p<0.05 作为唯一判据）。
7. 禁止预设特定交互组合或变量清单。
8. 不得注入旧论文结论、相关矩阵或用于引导特定发现的文献摘要。
9. 允许：数据字典、计算定义、基础物理知识、预注册的计算工具与搜索预算。

**允许注入**：本目录 `DATA_DICTIONARY.md`、`hard_constraints.json`、计算预算、工具白名单。

**审计**：每轮实验前，Agent manifest 需声明所用系统提示词哈希；
Physics Auditor 独立检查提示词是否含上列禁用方向（S01.4 冻结）。

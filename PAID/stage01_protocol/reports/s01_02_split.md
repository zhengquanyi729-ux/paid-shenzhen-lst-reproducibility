# S01.2 空间划分（发现—验证防火墙分区）

框架依据：§5.1 数据隔离设计；§5.2 Split manifest；§6 Exp.3 空间分块 / 缓冲验证。

## 1 规则

- 分区几何：对 100 m 格中心坐标做 k-means（k=5，seed=20260924，10 次重启），得 5 个连通 Voronoi 簇，整簇指派给 A/B/C —— **不做随机抽格**（S01.1 已证 LST 强空间自相关）。
- 簇连通性：各簇 8 邻域连通分量数 = [1, 1, 1, 1, 1]。
- 指派：{0: 3, 1: 1, 2: 1, 3: 1, 4: 2}（在 3^5 指派中先筛占比落在 (0.60,0.20,0.20)±0.03，再取 C 的地表覆盖偏离全局最小者）。
- 缓冲：**只对锁定区 C** 剔除距 A∪B < R 的格（R=15 格 = 1.5 km，来自 S01.1）。A 与 B 同属开发域，之间不设缓冲。

## 2 规模

- C 缓冲后连通分量数 = **1**。
- 最小间距（棋盘距离，格）：C↔A = 16，C↔B = 85，**C↔A∪B = 16**（应 ≥ R = 15）；A↔B = 1（不设约束）。

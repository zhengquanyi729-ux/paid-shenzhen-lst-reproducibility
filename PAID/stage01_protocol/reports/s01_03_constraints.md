## 2 硬约束集（21 条）

| ID | 类别 | 约束 | 状态 |
|---|---|---|---|
| DV-1 | 数据有效性 | 主样本 LST_mean 必须落在实测域 [27.815, 65.916] ℃ 内（逐格有效像元均值）。 | 可执行 |
| DV-2 | 数据有效性 | NDVI_mean ∈ [-0.2827, 0.8837]（实测域）。 | 可执行 |
| DV-3 | 数据有效性 | SVF_mean ∈ [0.3865, 1.0000]（0=全天空遮蔽，1=无遮蔽）。 | 可执行 |
| DV-4 | 数据有效性 | 分析仅使用主样本 (n=31760)；放宽样本 (n=32246) 仅用于稳健性复核，二者不得混入同一训练/评估切分。 | 可执行 |
| DV-5 | 数据有效性 | 缺失值（NaN）不得插补后参与主估计；含缺失的行须显式排除并登记。 | 可执行 |
| DV-6 | 数据有效性 | 全市域 LST==0 判为区外制图填充，一律无效；任何以 0 为真实温度的推断被禁止。 | 可执行 |
| DG-1 | 量纲与几何 | 所有候选项/表达式两侧量纲必须一致或已无量纲化；指数、对数、三角函数的自变量必须无量纲。 | 可执行 |
| DG-2 | 量纲与几何 | X_BD、X_BH、X_VolDens、Road_Dens 的**口径未确认**，只允许在无量纲化（标准化/排序/比值）后入模，且必须在候选登记中标注口径假设。 | 仅声明 |
| DG-3 | 量纲与几何 | 几何派生量（覆盖率、高度、体量密度）必须满足几何合法性（非负、覆盖率不应显著 >1，体量非负）；越界须报告而非截断。 | 可执行 |
| DG-4 | 量纲与几何 | 温度运算区分 ℃ 与 K；涉及辐射（如 T⁴、Stefan–Boltzmann）时必须用绝对温度 T_K = T_℃ + 273.15。 | 可执行 |
| MB-1 | 测量边界 | LST 观测支持尺度为 30 m 像元；100 m 格为聚合单元。不得把重采样/聚合表述为"新的温度观测分辨率"。 | 仅声明 |
| MB-2 | 测量边界 | SVF 为 5 m 源，与 30 m LST 不同源；不得视为 5 m 温度观测，使用前须显式重采样并声明。 | 仅声明 |
| MB-3 | 测量边界 | LST 不可当作气温（air temperature）使用。 | 仅声明 |
| MB-4 | 测量边界 | 观测时间为单一时相、元数据不可恢复；禁止开展日/夜、季节、热恢复动态推断。 | 可执行 |
| PC-1 | 物理一致性 | 能量闭合 Rn + QF = H + LE + G 在当前数据下**无法求解**：无净辐射、人为热、感热、潜热、地热通量任一输入。 | 不可计算 |
| PC-2 | 物理一致性 | 当前只允许执行"有数据支持"的物理一致性检查：量纲一致性、几何合法性、取值域、单调性/符号的**事后**审计（非预设）。 | 仅声明 |
| PC-3 | 物理一致性 | DEM 全域 3–17 m，不符合深圳实际地形（最高约 900 m 级）；在澄清口径前，DEM_mean 不得作为真实海拔或用于坡度/高程物理推断。 | 不可计算 |
| SI-1 | 统计诚信 | 看到锁定区 C 的测试结果后，不得修改同一轮的模型、指标、假设或停止条件。 | 可执行 |
| SI-2 | 统计诚信 | 每轮实验只追加记录，不得覆盖失败结果；失败候选与反例必须保留。 | 可执行 |
| SI-3 | 统计诚信 | 必须处理多重比较；搜索规模（候选数×检验数）须登记，偶然显著须以置换/分层等方法控制。 | 可执行 |
| SI-4 | 统计诚信 | B 区参与调参后不再视为独立确认；仅 C 区（锁定）与 D（外部）可用于独立确认。 | 可执行 |

汇总：可执行 **14** 条、仅声明 5 条、不可计算 2 条。

> **不可计算项的现实依据**：能量闭合缺全部通量输入；DEM 全域 3–17 m 不符合深圳地形。
> 二者在补齐数据前不得据此宣称任何物理机制一致性（禁止伪造能量残差）。

## 3 口径不确定性（须回溯作者）

| 变量 | 问题 | 处理 |
|---|---|---|
| X_BD | 最大值 1.770 > 1，不是 [0,1] 建筑覆盖率口径。 | 入模前无量纲化，登记口径假设；向作者回溯定义 |
| X_BH | 最大值 224.0 m，作为 100 m 格"平均建筑高度"不合理（疑为最大值或求和）。 | 同上 |
| X_VolDens | 与 X_BD·X_BH 的几何恒等式未证实：比值 p05/中位/p95 = 1.040/2.022/11.302。 | 不得假定恒等式；需作者给出体量密度定义 |
| DEM_mean | 全域 3–17 m；深圳地形可达 ~900 m，疑为掩膜或重标定。 | 禁止高程物理推断，回溯作者 |
| Road_Dens | 量纲未明（0–75.62，77% 为 0）。 | 仅按无量纲/序数处理 |
| NDVI 研究区栅格 | 文件名拼写为 NVDI_shenzhen.tif。 | 记录，不影响数值；登记为命名瑕疵 |

# 预注册协议（Stage 01 规则冻结）

**项目**：物理约束下城市地表热环境规律的 AI 自主科学发现研究框架（PAID）  
**阶段**：Stage 01 规则冻结（Table 17）  
**版本**：stage01-prereg-v1  |  **冻结日期**：2026-09-24

> 本协议在开放正式发现环境（Stage 02 及以后）之前冻结。
> 一旦冻结，M2 发现阶段中途不得更改约束、切分、主指标、预算与权限；
> 任何更改都构成新一轮预注册，须重走防火墙（§5.3）。

## 1 研究范围限定（源自 Stage 00）

- 观测元数据（时间/传感器/反演算法/QA）不可恢复 → 研究**限定为单一时相的空间分异**；
  日/夜、季节、热恢复动态分析一律不开展（S00.1，硬约束 MB-4）。
- 数据基线：`data/` 99 个原始文件、896.6 MB，SHA-256 见 Stage 00 manifest。
- 分析单元：100 m×100 m 网格（EPSG:32649），共 32748 格；
  **主样本 31760 格**（发现与建模），放宽样本 32246 格（仅稳健性复核）。

## 2 数据隔离设计（§5.1 发现—验证防火墙）

空间划分依据 S01.1 的**去相关尺度 R**：去趋势残差仍显著自相关（Moran’s I=0.886，伪 p=0.0050），建成/中层 r(k) 降至 0.2 的最大滞后 15 格，故取 **R = 15 格 = 1.5 km**。

> 注：下表「格数/占比」为**缓冲后分析样本**（A+B+C = 28353 格；主样本 31760 格中的 3407 格进入缓冲带、不再参与发现或验证），分母非主样本。

| 数据层 | 格数 | 占缓冲后样本 | 权限 |
|---|---|---|---|
| A 发现区 | 19184 | 67.7% | Agent 可多次实验、修改假设 |
| B 开发验证区 | 6182 | 21.8% | 方法筛选与稳健性；参与调参后不再视为独立确认 |
| C 锁定区 | 2987 | 10.5% | 仅 Independent Validator 持有目标值，候选冻结后解封 |
| D 外部验证集 | — | — | 新时相/新地区，独立收集，不从 A–C 再切分 |

- 缓冲：仅对 C 施加，剔除 C 中距 A∪B < R 的 3407 格；A 与 B 同属开发域，不设内部缓冲。
- 距离核验：C↔A∪B = 16 格 ≥ R = 15 格（八邻域膨胀测距）。
- C 区连通性：缓冲后连通分量数 = 1（保持空间连续，非碎片化）。
- 禁随机抽格：划分基于 5 个连通 k-means 簇整簇指派（seed 20260924）。

## 3 已知局限（须在论文如实声明）

1. **地表覆盖偏斜**：连通分块下 C 区的 NDVI 三分位构成为 [0.338, 0.548, 0.115]，偏离全局 [0.333, 0.333, 0.333]（指派时的 L1 距离 0.2445，见 S01.2 报告）。这是连续空间分区与深圳地表覆盖空间聚集共同导致的内在局限，非抽样失误；L2 结论的适用范围须据此限定。
2. **口径未确认的协变量**：X_BD（max 1.77）、X_BH（max 224.0 m）、X_VolDens（与 X_BD·X_BH 恒等式未证实）、DEM（3–17 m，不合地形）、Road_Dens（量纲未明）——仅可无量纲化入模，且须登记口径假设（§3 硬约束 DG-2 / PC-3）。
3. **不可逆缺口**：观测元数据缺失；CSV 导出时的 61 格剔除条件与栅格二次掩膜依据未留存。
4. **预训练先验**：不得宣称 Agent 无绝对先验；可操作主张为「提示词不注入目标领域结论、研究者不按结果引导、全过程可审计」（§4.3）。

## 4 物理约束与无方向预设（§3）

- 硬约束 **21 条**（可执行 14 / 仅声明 5 / 不可计算 2），见 `constraints/hard_constraints.json`。
- 能量闭合、DEM 高程推断标为 **not_computable**：缺通量输入、DEM 值不合地形，禁止伪造能量残差或机制叙事。
- 无方向预设：冻结 9 条系统提示词禁用主张（NDVI/SVF/建高方向、最优尺度、固定函数式、单一显著阈值、交互组合），见 `constraints/no_direction_preset.md`。

## 6 Agent 权限与预算

| Agent | 可访问数据 | 禁止访问 |
|---|---|---|
| Discovery Agent | A 发现区 | B 开发验证区（调参用，不下发目标）；C 锁定区目标值；旧论文结论/相关矩阵 |
| Experiment Agent | A 发现区、B 开发验证区 | C 锁定区目标值 |
| Falsification Agent | A 发现区、B 开发验证区、分区掩膜（row/col/zone） | C 锁定区目标值 |
| Physics Auditor | constraints/hard_constraints.json、constraints/DATA_DICTIONARY.md、全部分区掩膜 | C 锁定区目标值 |
| Independent Validator | locked/zone_C_targets.csv、已冻结候选登记 | 不得向开发域回传 C 目标值（只发布聚合后的通过/失败与不确定性） |

- 候选上限：每轮 ≤ 50；总 fit 预算 5000；冻结候选 ≤ 8。
- 开发主指标：A 发现区空间分块交叉验证 RMSE（℃），分块=连通簇，块数≥5。
- 停止条件：连续 200 次 fit 无开发指标改进；累计 fit 达 5000 次预算；冻结候选数达上限 8；反例/混杂检验使所有候选被否决（允许以「暂无经证伪仍成立的候选」结束）

## 7 验证协议要点

- 主终点：候选表达式在 C 区的 RMSE（℃）以及相对 Baseline A 的 ΔRMSE；通过条件：ΔRMSE>0（优于 Baseline A）且经 199 次空间块置换检验 p<0.05，且 95% 置信区间不跨 0，且物理审计通过，且负对照（空间置换/随机目标）未通过。
- 空间推断：199 次空间块置换；多重比较：Holm–Bonferroni（family = 冻结候选集）；同时报告未校正 p；缺失：C 区不插补；缺失/无效格显式排除并登记数量。
- 解封原则：哈希≠访问控制；C 目标值存于发现 Agent 无权读取的独立目录/服务；验证只接受已冻结候选，发布完整通过/失败（§5.3）。

## 8 证据分类与结论边界（§7）

| 类别 | 证据要求 | 表述边界 |
|---|---|---|
| L1 探索性模式 | 仅在发现/开发集存在 | 待确认候选，不称为新规律 |
| L2 空间稳健关系 | 深圳锁定空间区（C）重复成立 | 适用于被检验的观测条件 |
| L3 外部支持关系 | 独立时相/城市（D）重复成立 | 明确迁移范围及条件 |
| L4 机制进一步验证 | 补充独立物理或干预证据 | 可谨慎讨论机制，不超越证据 |

允许 AI 最终得出「尚无经独立验证的新规律」的结论；科学价值由可复核的发现与证据决定，而非候选数量或预测精度（§10）。

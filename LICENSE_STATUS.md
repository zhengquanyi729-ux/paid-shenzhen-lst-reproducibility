# Licensing status

Code licensing is now resolved. This file records the change of status; the operative text is
`LICENSES/MIT-CODE.txt` (for code) plus `docs/LICENSING.md` (the full licensing statement).

**Author-owned source code is licensed under the MIT License. See `LICENSES/MIT-CODE.txt`.** MIT
applies to author-owned source code in:

- `PAID/`
- `release_tools/`
- `verification/`

except where an individual file explicitly states otherwise.

**The MIT licence does not apply automatically to data, figures, manuscript text, or
third-party-derived materials.** The following are **not** covered automatically by the MIT licence:

- `data/`
- `figures_source/`
- `manuscript_submission/`
- third-party-derived artefacts
- materials carrying separate upstream terms

Data licensing remains file-specific. See `docs/LICENSING.md`.

## History of this status

This notice previously read that *final licensing had not yet been assigned* and that no licence was
granted by the repository. That was accurate at the time. Following the provenance and
redistribution-rights audit (`docs/SHENZHEN_LICENSING_REVIEW.md`,
`docs/PUBLIC_RELEASE_LICENSING_GATE.md`), the **code** side is now resolved: the authors apply the
**MIT License** to the author-owned source code only. The **data** side is deliberately left
unresolved — no blanket data licence is granted — because upstream terms and relicensing rights remain
unconfirmed. This file is not itself a licence; the licence for code is `LICENSES/MIT-CODE.txt`.
